Building this portfolio: from a work archive to a product

How I organized my work into a bilingual website connecting projects, tools and evidence.

Matías Gaglio · 08/11/2026

Leer en español

Finding a common thread

My work spans advertising, analytics, content and development. Building this website meant finding a structure that explains what I did, why I did it and what supports each claim. A résumé summarizes a career; here I can show the process and let visitors explore their interests.

A catalog as the entry point

The site uses a marketplace-inspired interface with categories, search and detail pages. Each project becomes something visitors can discover by topic. Amazon work, Predestinato and Telemetry One share a catalog while retaining their own context.

Separating content from presentation

Core pages use shared templates and structured content files. Python generates static pages; HTML, CSS and JavaScript handle presentation and interaction. A search index feeds the catalog. This structure makes updates manageable and supports Spanish and English versions.

Working with AI requires judgment

I use ChatGPT and Codex to explore solutions, write code and review changes. I still define the problem, choose the evidence and assess the result. A page can build successfully while explaining a project poorly, so I review the writing as well as the navigation.

Checking quality in concrete ways

The repository includes link, localization and metadata validation, Playwright interface tests and accessibility checks. These help detect repeatable problems. Screenshots, mobile review and editorial reading help assess whether the experience makes sense and whether evidence is easy to find.

A website that evolves with my work

Predestinato, Telemetry One, Oxi and Revolution projects keep expanding the story. Maintaining this portfolio means revisiting the selection, updating articles and connecting work across disciplines. Building the site is itself an example of how I organize information and turn an idea into a usable experience.
