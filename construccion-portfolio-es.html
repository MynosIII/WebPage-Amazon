Construir este portfolio: del archivo de trabajos a un producto

Cómo organicé mi trabajo en un sitio bilingüe que conecta casos, herramientas y evidencia.

Matías Gaglio · 08/11/2026

Read in English

El problema era encontrar un hilo

Mi trabajo reúne publicidad, análisis, contenido y desarrollo. Al construir esta página, el desafío fue darles una estructura que permita entender qué hice, por qué y con qué evidencia. El CV resume una trayectoria; acá puedo mostrar el proceso y dejar que cada persona explore lo que le interesa.

Un catálogo como puerta de entrada

El sitio incorpora una interfaz inspirada en un marketplace: categorías, búsqueda y páginas de detalle. Esa decisión convierte cada proyecto en una entrada que se puede descubrir por su tema. Alguien interesado en Amazon puede recorrer casos comerciales; alguien interesado en desarrollo puede llegar a Predestinato o Telemetry One desde el mismo catálogo.

Contenido separado de la presentación

Las páginas principales parten de archivos de contenido y plantillas compartidas. Python genera versiones estáticas; HTML, CSS y JavaScript resuelven la presentación y las interacciones. El catálogo se alimenta de un índice de búsqueda. Esta estructura permite actualizar información sin rehacer cada pantalla y conservar una versión navegable en español y otra en inglés.

Trabajar con IA también exige revisar

Uso ChatGPT, Codex y Claude Code como parte del desarrollo: para explorar soluciones, escribir código, auditar el sitio y revisar cambios. Mi trabajo sigue siendo definir el problema, elegir qué vale la pena mostrar y evaluar el resultado. Una página puede compilar y aun así explicar mal un proyecto. Por eso reviso tanto el contenido como la navegación.

Auditorías que terminan en cambios

Las auditorías con Claude Code encontraron problemas que no se veían a simple vista. El catálogo y el carrusel de herramientas dependían de JavaScript, así que un buscador o un bot de vista previa veía una lista vacía; ahora la compilación genera una versión estática y el sitemap pasó de 5 a 36 páginas. También se reemplazó una imagen para redes que mostraba el dominio anterior y se corrigió un selector CSS que agrandaba los logos de software. Cada cambio se publicó en Vercel y se verificó en producción.

La calidad necesita comprobaciones concretas

El repositorio incluye validaciones de enlaces, traducciones, metadatos y etiquetas de software, además de pruebas de interfaz con Playwright y controles de accesibilidad. Son herramientas para detectar errores repetibles. Las capturas, la lectura en móvil y la revisión editorial completan ese trabajo: ayudan a comprobar si el sitio se entiende y si las pruebas de cada caso están a mano.

Una página que cambia con mi trabajo

Predestinato, Telemetry One, Oxi y los proyectos de Revolution amplían lo que este portfolio puede contar. Mantenerlo implica volver sobre la selección, actualizar artículos y conectar trabajos que antes parecían separados. La construcción de esta página es, también, una muestra de cómo organizo información y convierto una idea en una experiencia utilizable.
