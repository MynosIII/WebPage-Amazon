Contrato metodológico

La frontera más importante es temporal.

Para reconstruir cada predicción, el modelo trabaja con la información disponible antes de la primera práctica: ratings acumulados, forma previa, circuito, pronóstico y confiabilidad histórica. Después del Gran Premio incorpora el resultado y avanza.

Tres capas de aprendizaje

Una combinación que puede corregir su propia confianza.

Elo multicompetidor

Ratings globales, duelos contra el compañero y ritmo del constructor se actualizan mediante sorpresa: resultado observado menos resultado esperado.

Gradient boosting

Antes de cada carrera, un modelo de ventana expansiva se ajusta con todas las pruebas anteriores y aprende interacciones no lineales.

Mezcla Hedge

Después de cada ronda, multiplicative weights desplaza confianza hacia la capa que ordenó mejor ese pelotón.

Riesgos separados

Clasificadores adicionales estiman abandono por accidente y por falla mecánica, y se evalúan por calibración.

Cómo se hizo

Reconstruir 75 años sin dejar que el futuro se filtre hacia atrás.

El proceso ordena cada Gran Premio por fecha y reproduce una secuencia fija: construir variables, entrenar con el pasado disponible, predecir, guardar la predicción, revelar el resultado y actualizar el estado. Esa disciplina evita que una victoria, una mejora técnica o un abandono influya en la estimación que supuestamente se hizo antes de que ocurriera.

Las variables no se tratan como una fotografía única. El rendimiento del piloto cambia carrera a carrera; el duelo con el compañero separa parte del efecto del auto; el constructor acumula su propio ritmo; la forma usa ventanas móviles; y el fingerprint del circuito permite transferir experiencia entre trazados parecidos. Cuando una señal todavía no existía históricamente, el pipeline utiliza solo el sustituto disponible para esa época.

Antes de cada ronda, el gradient boosting se vuelve a ajustar con una ventana expansiva. En paralelo, los ratings Elo producen una lectura más interpretable de capacidad relativa. La mezcla Hedge observa cuál de las capas ordenó mejor el último pelotón y modifica su peso para la siguiente carrera. El sistema no elige un ganador fijo entre modelos: aprende cuánto confiar en cada uno a medida que avanza la historia.

Del modelo al análisis

La predicción también sirve para entender por qué una carrera es difícil de anticipar.

Guardar cada pronóstico antes del resultado permite mirar mucho más que el promedio final. Se pueden localizar épocas donde el auto domina la señal, circuitos donde la similitud ayuda, temporadas con mayor incertidumbre y fines de semana donde accidente y confiabilidad alteran el orden competitivo. El error deja de ser un único número y se convierte en material para investigar.

Capacidades demostradas

Un laboratorio personal de análisis deportivo.

  • Modelado temporal: construí un flujo que aprende en orden cronológico y reproduce las condiciones de información de cada Gran Premio.
  • Ingeniería de variables: combiné piloto, constructor, circuito, clima, forma y confiabilidad en señales comparables a través de 75 años.
  • Evaluación rigurosa: contrasté el sistema con una línea base competitiva y medí ranking, ganador, podio, calibración e incertidumbre.
  • Análisis exploratorio: el modelo permite comparar eras, descubrir patrones y formular preguntas nuevas sobre rendimiento y contexto.
  • Construcción reproducible: código, tests y resultados forman una base que se puede inspeccionar, extender y conectar con Telemetry 1.
